📸 Eveerstory — Instagram Clone
By Dhruv Jain

A full-featured Instagram-like social media platform built with MERN stack.

🚀 Features
Follow / Unfollow users

Search users

View posts from followed users

Create new posts

Comment on posts

Like / Unlike posts

JWT-based Authentication

Update user profile

🛠️ Tech Stack
Frontend: React.js

Backend: Express.js

State Management: Redux Toolkit

Database: MongoDB Atlas

Styling: Styled Components

Routing: React Router Dom V6

Icons: Iconsax React Icons

Cloud Storage: Cloudinary
